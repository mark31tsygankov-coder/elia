# Для Эли 💕

Простой сайт с вопросами «как дела».

## Как закинуть на GitHub Pages

1. Создай новый репозиторий на GitHub (например `elia` или `for-elia`).
2. Загрузи **все файлы из этой папки** прямо в корень репозитория (без вложенных папок).
3. Зайди в Settings → Pages → Source: Deploy from a branch → Branch: `main` / `root`.
4. Через минуту сайт будет доступен по адресу `https://твой-ник.github.io/название-репо/`

## Файлы

- `index.html` — главная страница
- `style.css` — стили
- `script.js` — логика
- `admin.html` — админка (пароль: **elia2025**)
- фотки `IMG_*.jpg`

## Админка

Внизу сайта есть ссылка «Админка».  
Пароль по умолчанию: `elia2025`  
Можешь поменять его в файле `admin.html` (найди строку `const PASSWORD = 'elia2025';`).

Ответы хранятся в браузере (localStorage).  
Чтобы увидеть ответы Эли — нужно открыть админку **в том же браузере**, где она отвечала, либо попросить её прислать скрин / скопировать.

Если нужно, чтобы ответы приходили тебе на почту — можно потом подключить Formspree или Google Forms.
